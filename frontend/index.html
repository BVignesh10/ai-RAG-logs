How it works

Four steps from raw logs to an answer.

Step 1

Ingest

Paste or upload logs in any format. They are parsed and split into chunks.

Step 2

Embed and index

Sentence Transformers turn each chunk into a vector stored in FAISS.

Step 3

Retrieve

Your question pulls the most relevant chunks as context for the model.

Step 4

Analyze

LLaMA 3 on Groq returns the root cause, severity, and fix steps.

What LogSense does

Built to shorten the time between an alert and a fix.

Root cause analysis

Finds the underlying cause of a failure, not just the symptoms.

Severity labels

Every finding is tagged INFO, WARNING, or CRITICAL so you know what to fix first.

Fix suggestions

Concrete steps to resolve the issue, so you skip the stack-trace searching.

Chat with your logs

Ask follow-ups, narrow to one service, or request a summary.

Fast answers

FAISS search and Groq inference keep responses quick, even on large files.

Keys stay private

API keys live in a .env file, never in code. Logs are handled in-session.

Built for real DevOps problems

LogSense AI is an end-to-end RAG pipeline that makes log analysis conversational. Instead of grepping thousands of lines, ask a question and get an answer grounded in your own log data.

It combines a FastAPI backend, sentence-transformer embeddings, FAISS vector search, and LLaMA 3 on Groq for fast inference.
